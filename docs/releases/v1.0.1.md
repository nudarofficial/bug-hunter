# Bug Hunter v1.0.1

This release updates the copyright holder and clarifies the skill, based on testing it against bugs it had never seen.

## What changed

- **Copyright** is now held by **Nudar** (MIT License).
- **Clearer skill instructions** from testing three new scenarios:
  - a Python fix
  - a JavaScript code review
  - a crash report with no trace provided

  In all three the skill found the root causes, separated confirmed findings from potential risks, and did not invent evidence. The test agents also reported where the instructions were ambiguous. Those points are now fixed:
  - **Not enough evidence:** Claude stops and asks for the exact trace, code, and versions, with per-language tips for capturing a trace.
  - **Find/review vs. fix:** review requests propose fixes without editing code.
  - **Confirmed findings** say how they were confirmed: reproduced, observed, or traced without running.
  - **Report format** depends on how many findings there are.
  - **Second bugs, missing test frameworks, behavior changes, and severity without callers** each have explicit rules.
- **New pitfalls** apply to every language: off-by-one bounds, truthiness checks, argument mutation, caches, and float money. There is also a new JavaScript entry on plain objects used as maps.

Full test write-up: [docs/skill-test-results.md](https://github.com/nudarofficial/bug-hunter/blob/main/docs/skill-test-results.md)

## Install

Download `bug-hunter-v1.0.1.zip` from the assets below.

- **Claude Code:** unzip into `~/.claude/skills/` so that you have `~/.claude/skills/bug-hunter/SKILL.md`.
- **claude.ai:** upload the ZIP in the Skills section of Settings. You need a plan with code execution enabled.
- **Claude API:** upload the `bug-hunter` folder through the Skills API (`/v1/skills`).

## Verify the download

```bash
sha256sum -c bug-hunter-v1.0.1.zip.sha256
```

On Windows PowerShell, compare `(Get-FileHash .\bug-hunter-v1.0.1.zip -Algorithm SHA256).Hash.ToLower()` with the hash in the `.sha256` file.
