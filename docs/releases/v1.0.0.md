# Bug Hunter v1.0.0

First public release of **Bug Hunter**, an Agent Skill for Claude. It guides evidence-based debugging, root-cause analysis, and minimal bug fixes.

## Highlights

- **Disciplined workflow.** A nine-step process from defining the bug to reporting what was and was not verified.
- **Honest reporting.** Findings are labelled Confirmed, Potential risk, Needs verification, Ruled out, or "Traced, not executed". The skill is told never to invent stack traces, test results, reproductions, or performance numbers.
- **Minimal fixes with regression review.** Every fix comes with a checklist covering callers, edge cases, concurrency, error paths, security, and performance.
- **Reference material loaded on demand:**
  - stack-trace reading for 9 language families
  - pitfalls for Python, JavaScript, TypeScript, Java, C, C++, C#, Go, Rust, PHP, Ruby, and SQL
  - security (source → sink) and performance (measure first) guides
  - a report template
  - 13 worked examples
- **Runnable examples.** Python and JavaScript bugs, each with a test that fails on the buggy code and passes on the fix.

## Install

Download `bug-hunter-v1.0.0.zip` from the assets below.

- **Claude Code:** unzip into `~/.claude/skills/` (personal) or `.claude/skills/` in a project, so that you have `~/.claude/skills/bug-hunter/SKILL.md`.
- **claude.ai:** upload the ZIP in the Skills section of Settings. This needs a plan with code execution enabled; see Anthropic's help article "Using Skills in Claude".
- **Claude API:** upload the `bug-hunter` folder through the Skills API (`/v1/skills`).

## Verify the download

```bash
sha256sum -c bug-hunter-v1.0.0.zip.sha256
```

On Windows PowerShell:

```powershell
(Get-FileHash .\bug-hunter-v1.0.0.zip -Algorithm SHA256).Hash.ToLower()
```

Compare the output with the hash in `bug-hunter-v1.0.0.zip.sha256`.

## Known limitations

- The skill guides Claude's reasoning; it does not run static analysis or debuggers by itself. How much it can verify depends on the tools available on each surface (for example, the Claude API sandbox has no network access).
- The runnable examples cover Python and JavaScript. Examples for the other languages are worked explanations that were not executed.
- The evaluation scenarios in `evals/` are rubrics. Agent Skills has no built-in evaluation runner.
