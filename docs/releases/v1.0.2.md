# Bug Hunter v1.0.2

This maintenance release came out of a full review of the repository.

## Fixed

- **Skill instruction:** step 8 suggested `git stash` to show that a new regression test fails before the fix. Stashing would also hide the new test, so the step now says to write and run the test *before* applying the fix.
- **CI deprecation warning:** the workflow used actions that run on deprecated Node.js 20. They are updated to `checkout@v5`, `setup-python@v6`, and `setup-node@v5`, and the JavaScript example now runs on Node.js 24 LTS.
- **Python support claim:** the minimum is now Python 3.10, and CI tests 3.10 and 3.13. The earlier "3.9 or later" claim was never tested.
- **Issue template:** the placeholder no longer names a made-up Claude Code version.

## Added

- `CODE_OF_CONDUCT.md`
- Dependabot configuration that keeps GitHub Actions current
- A fuller project tree in the README

## Install

Download `bug-hunter-v1.0.2.zip` below and unzip it into `~/.claude/skills/`, so that you have `~/.claude/skills/bug-hunter/SKILL.md`. For claude.ai, upload the ZIP in the Skills section of Settings. Verify it with:

```bash
sha256sum -c bug-hunter-v1.0.2.zip.sha256
```
