# Bug Hunter v1.0.3

This release comes from the first end-to-end tests in the real Claude Code CLI (`claude -p`, model Sonnet 5.5, skill installed in `.claude/skills/`).

## What the tests showed

- **Automatic triggering is not guaranteed.** Claude often handled simple-looking bugs without loading the skill. It still found the bugs, but it skipped the skill's discipline: no regression test, and no reproduction.
- **Explicit `/bug-hunter` always uses the skill**, and the output followed its rules.

## Changes

- **Stronger description.** It now says to use the skill "even when the bug looks small or obvious". After this change, a code-review request triggered the skill automatically; before it, none of the three test requests did.
- **New rule: every fix gets a regression test.** The test runs before the fix (fails) and after it (passes), or the report says why not. With this rule, the `/bug-hunter` run reproduced the failure first, fixed it in one line, and added a regression test.
- **README:** recommends starting requests with `/bug-hunter` in Claude Code, or saying "use bug-hunter" on claude.ai.

Full results: [docs/skill-test-results.md](https://github.com/nudarofficial/bug-hunter/blob/main/docs/skill-test-results.md)

## Install

Download `bug-hunter-v1.0.3.zip` below and unzip it into `~/.claude/skills/`, so that you have `~/.claude/skills/bug-hunter/SKILL.md`. For claude.ai, upload the ZIP in the Skills section of Settings. Verify it with:

```bash
sha256sum -c bug-hunter-v1.0.3.zip.sha256
```
